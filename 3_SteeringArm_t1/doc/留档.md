## 一、J3 夹爪实测标定

| CCR | 实际状态 | 说明 |
|:---:|:---------|:------|
| 5000 | 全开 | 夹爪张开至最大 |
| 4000 | 半开 | 约 50% |
| 3200 | 中位开口 | 开口刚可进物 ← **回中位置** |
| 3000 | 近夹 | 刚接触物体但未夹紧 ← **安全下限** |
| 2950 | 闭合无夹紧 | 夹爪合拢无夹持力 |
| 2940 | 完全闭合 | 完全闭合无夹持力 |
| 2930 | 夹紧 | 开始产生夹持力 |
| <2000 | ❌ 抱死过流 | 禁止使用 |

**关键发现**：GRIPPER_PULSE_OPEN/CLOSE 标注与实际相反。config 标 OPEN=1000 实际是抱死区，实测 5000=全开。

## 二、代码 Bug 修复汇总

| 文件 | 改动 | 关联问题 |
|:----|:-----|:---------|
| [can_rx_task.c](can_rx_task.c) | 多关节/增量/绝对三模式加 J1/J2 角度限幅 `J1_ANGLE_MIN/MAX` | 限位宏是死定义 |
| [can_rx_task.c](can_rx_task.c) | R2 增量模式新增 `case 3: gripper_target` | J3 增量完全失效 |
| [can_rx_task.c](can_rx_task.c) | 多关节 J3 映射：`uint8 0~200 → CCR 5000~3000` | 原直接赋值 0~200 到 gripper_target |
| [servo_task.c](servo_task.c) | R2 初始化 `gripper_target=3000→3200` | 零值 clamp 到 1000 抱死过流 |
| [servo_task.c](servo_task.c) | 首次激活改从 MT6701 读真实位置 | 第一个运动不受速度控制 |
| [can_rx_task.c](can_rx_task.c) | 分离 `g_servo_active`(首次激活) 和 `g_system_locked`(锁定) | 锁定后被 0x130 绕过 |
| [can_rx_task.c](can_rx_task.c) | 0x131(ARM_VEL) 移除，统一走 0x430#02 | 速度设置不生效 |
| [can_rx_task.c](can_rx_task.c) | `430#01` 回中触发首次激活 | 回中不受速度控制 |
| [arm_state_task.c](arm_state_task.c) | 0x330 flags 新增 bit2=系统锁定 | 上位机读不到锁定状态 |
| [app_arm_cfg_r2.h](App/config/app_arm_cfg_r2.h) | 修正 GRIPPER_PULSE_OPEN/CLOSE 标注; J1_ANGLE_OFFSET=-20 | 标注与实际相反 |

## 三、初始位置

规定：J1(大臂)=-45°, J2(小臂)=-90°, J3(夹爪)=3200(中位开口)

```bash
# 一键到初始位置（多关节，mask=0x0E 含 J1+J2+Gripper）
cansend can0 130#120E3EFE7CFCB400
```
gripper=0xB4=180 → 5000−180×10=3200 ✓

## 四、完整 CAN 指令集

详见 `doc/测试指南.md` 第六章 R2 舵机臂。

### 核心命令快速参考

```bash
# 上电流程（可先设速度再回中，第一个运动就按设定速度走）
cansend can0 430#0400000000000000   # 解锁
cansend can0 430#0258020000000000   # 设速度 60°/s（可选，默认 180°/s）
cansend can0 430#0100000000000000   # 回中 (J1=0, J2=0, J3=3200)

# J1/J2 绝对
cansend can0 130#1101840300000000   # J1=90°
cansend can0 130#11013EFE00000000   # J1=-45°
cansend can0 130#1102C20100000000   # J2=45°
cansend can0 130#11027CFC00000000   # J2=-90°

# J3 夹爪
cansend can0 130#1103881300000000   # 全开 5000
cansend can0 130#1103800C00000000   # 中位开口 3200
cansend can0 130#1103720B00000000   # 夹紧 2930

# J1/J2 增量
cansend can0 130#2101640000000000   # J1 += 10°
cansend can0 130#21019CFF00000000   # J1 -= 10°

# J3 增量
cansend can0 130#2103C80000000000   # J3 += 200 (开大)
cansend can0 130#210338FF00000000   # J3 -= 200 (收小)

# 多关节
cansend can0 130#120E3EFE7CFCB400   # J1=-45°+J2=-90°+J3=3200
cansend can0 130#120E84032C016400   # J1=90°+J2=30°+Grip半开

# 速度（通过 0x430#02，废弃 0x131）
cansend can0 430#02B80B0000000000   # J1+J2 = 300°/s
cansend can0 430#0258020000000000   # J1+J2 = 60°/s (慢速)
```

### 标准调速流程

```bash
# 先设速度再运动，第一个动作就受控
cansend can0 430#0400000000000000   # 1. 解锁
cansend can0 430#0258020000000000   # 2. 设 J1+J2=60°/s
cansend can0 430#0100000000000000   # 3. 回中 → 60°/s 慢速回中
cansend can0 130#1101840300000000  # 4. J1→90° → 60°/s 慢速到达
cansend can0 430#02B80B0000000000   # 5. 改快速 300°/s
cansend can0 130#1101000000000000   # 6. J1→0° → 300°/s 快速回中
```

## 六、关节命名

| 关节 | 物理意义 | 硬件 |
|:----|:---------|:-----|
| **J0** | 基座旋转 | ⛔ R2 已机械锁死 |
| **J1** | 大臂摆动（第一关节） | TIM4_CH1 (PB6) |
| **J2** | 小臂摆动（第二关节） | TIM4_CH2 (PB7) |
| **J3** | 夹爪（末端 tool frame） | TIM4_CH3+CH4 (PB8+PB9) |

|:----|:-------|:----|:------------|

## 八、已知限制

- 多关节 J3 mask 必须含 0x08
- 驱动层无位置闭环（MT6701 仅做显示）
- 标定数据硬编码（换臂需重新编译）
- 无 CAN 超时保护（断线后保持最后位置）
- 无错误应答（非法命令静默忽略）
- 无固件版本号
