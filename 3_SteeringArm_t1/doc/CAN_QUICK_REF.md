# R2 舵机臂 — CAN 快速参考卡

> 给不熟悉代码的人：只需读这张卡就能发指令控制机械臂。
> 所有命令通过 CAN 总线发送，CAN ID 固定，无需了解内部实现。

---

## 上电顺序（必须按此流程）

```
Step 0: 确保 CAN 总线有至少两个节点（STM32 + USB2CAN/PCAN）
Step 1: cansend can0 430#0400000000000000     ← 解锁（不解锁舵机不动）
Step 2: cansend can0 430#0100000000000000     ← 回中（J1=0°, J2=0°, J3=3200）
Step 3: 发送关节控制指令
```

---

## CAN ID 速查

| ID | 方向 | 功能 | 简写名 |
|:--:|:----:|------|:------:|
| **0x130** | 发→臂 | 关节角度控制 | ARM_CMD |
| **0x131** | 发→臂 | 关节速度设置 | ARM_VEL |
| **0x230** | 发→臂 | 状态查询 | ARM_QUERY |
| **0x330** | 臂→发 | 状态上报（自动 50ms 一帧） | ARM_STATUS |
| **0x430** | 发→臂 | 系统配置 | ARM_CONFIG |

---

> **⚠️ R2 构型说明**：J0 (基座旋转, DC 电机) 已机械锁死，不供电不驱动。
> 可控关节：**J1=大臂摆动(第一关节)** · **J2=小臂摆动(第二关节)** · **J3=夹爪(末端)**

## 0x130 — 关节控制（最常用）

### 方式 A：单关节绝对位置

```
格式: 11 [joint_id] [value_L] [value_H] 00 00 00 00
      ↑                      ↑
      cmd=0x11               int16 LE
```

**J1（大臂摆动/第一关节）** — value = 角度×10

| 目标 | value | LE 字节 | cansend |
|:----|:-----|:--------|:--------|
| J1=0° | 0 | 00 00 | `130#1101000000000000` |
| J1=90° | 900 | 84 03 | `130#1101840300000000` |
| J1=-45° | -450 | 3E FE | `130#11013EFE00000000` |
| J1=45° | 450 | C2 01 | `130#1101C20100000000` |

**J2（小臂摆动/第二关节）** — 同 J1 编码

| 目标 | value | LE 字节 | cansend |
|:----|:-----|:--------|:--------|
| J2=0° | 0 | 00 00 | `130#1102000000000000` |
| J2=45° | 450 | C2 01 | `130#1102C20100000000` |
| J2=-90° | -900 | 7C FC | `130#11027CFC00000000` |

**J3（夹爪）** — value = 原始 CCR 脉宽

| 目标 | value | LE 字节 | cansend |
|:----|:-----|:--------|:--------|
| 全开 | 5000 | 88 13 | `130#1103881300000000` |
| 中位开口 | 3200 | 80 0C | `130#1103800C00000000` |
| 近夹(底线) | 3000 | B8 0B | `130#1103B80B00000000` |
| 夹紧 | 2930 | 72 0B | `130#1103720B00000000` |

### 方式 B：单关节增量

```
格式: 21 [joint_id] [delta_L] [delta_H] 00 00 00 00
```

| 指令 | cansend |
|:----|:--------|
| J1 += 10° | `130#2101640000000000` |
| J1 -= 10° | `130#21019CFF00000000` |
| J3 += 200 (开大) | `130#2103C80000000000` |
| J3 -= 200 (收小) | `130#210338FF00000000` |

### 方式 C：多关节同步

```
格式: 12 [mask] [J1_L] [J1_H] [J2_L] [J2_H] [grip] [J0]
```

mask: `0x02=J1` · `0x04=J2` · `0x08=Gripper`（要动哪个关节就置位）

| 指令 | cansend | 含义 |
|:----|:--------|:-----|
| J1=90°+J2=30° | `130#120684032C010000` | mask=0x06 |
| J1=45°+J2=-30° | `130#1206C201D4FE0000` | mask=0x06 |
| J1=-45°+J2=-90°+J3=3200 | `130#120E3EFE7CFCB400` | mask=0x0E |
| J1=90°+J2=30°+J3半开 | `130#120E84032C016400` | mask=0x0E |

> gripper 字节：0=全开(5000), 100=半开(4000), 180=中位开口(3200), 200=安全底线(3000)

## 0x430 — 系统配置

| 指令 | cansend | 效果 |
|:----|:--------|:------|
| **回中** | `430#0100000000000000` | J1=0°, J2=0°, J3=3200 |
| **设速度** | `430#02[B8 0B]00000000` | J1+J2 = 300°/s |
| **锁定** | `430#0300000000000000` | 舵机输出冻结（急停） |
| **解锁** | `430#0400000000000000` | 恢复舵机输出 |

| 触发一帧上报 | `230#0100000000000000` | 立即回一帧 0x330 |

## 0x330 — 状态上报（自动接收，50ms/帧）

```
Byte 0-1:  J1 raw angle (uint16 LE, 0~16383, MT6701)
Byte 2-3:  J2 raw angle (uint16 LE, 0~16383)
Byte 4:    gripper_target / 200 (0~25, 对应 CCR 0~5000)
Byte 5:    J0 speed (int8, 当前未用)
Byte 6:    flags: bit0=J1到位, bit1=J2到位, bit2=系统锁定
Byte 7:    0x00
```

> flags=0x03 表示 J1+J2 都已到达目标位置。

## 常见问题

| 现象 | 几乎肯定原因 | 解决 |
|:----|:-----------|:-----|
| 发指令后无反应 | **没解锁** | 先发 `430#04` |
| 发指令后串口报 `CAN_ERR: ACK` | **CAN 总线只有一个节点** | 把 USB2CAN/PCAN 接上 |
| 夹爪抱死过流 | **脉宽 < 2800** | 立刻发 `130#1103800C00000000` 回到 3200 |
| 关节不动但其他关节正常 | 对应关节舵机供电/信号线问题 | 检查线缆 |
| 0x330 收不到 | USB2CAN 未开 / ACK 错误 | `ip link set can0 up type can bitrate 500000` |
| 手臂抖动 | 速度太快 | `430#02[58 02]00000000` 设 J1+J2=60°/s 慢速 |
| 增量命令无效 | 固件不是最新 | 需包含增量 J3 修复的版本 |
| 多关节 J3 不动 | mask 不含 0x08 | 检查 bitmask 是否包含 Gripper 位 |
| 串口无打印但 CAN 正常 | 日志被关 | `230#04` 重新开启 |

## 最关键的两条保命指令

```bash
# 急停
cansend can0 430#0300000000000000     # 锁定（舵机立即冻结）

# 回到安全位置
cansend can0 430#0100000000000000     # J1=0° J2=0° J3=3200(开口)
```
