## 2026-07-06 — CAN 无法发送问题修复

### 现象
CAN `0x330` 状态上报无法发送，串口打印 `CAN_TX_FAIL: mailbox full or CAN not ready`，但无任何 CAN 错误中断触发。

### 根因
**ISR 中回环发送占满 TX mailbox** — `HAL_CAN_RxFifo0MsgPendingCallback`（`stm32f1xx_it.c`）每收到一条 CAN 报文，立即原样回发，快速耗尽仅有的 3 个 TX mailbox。后续 `Arm_State_Task` 调用 `HAL_CAN_AddTxMessage` 无空 mailbox 可用 → 静默失败。

叠加 `AutoRetransmission = ENABLE`，无法发送的报文在 mailbox 中持续重试永不释放，问题不可恢复。

### 修改

| 文件 | 修改 |
|------|------|
| `Core/Src/stm32f1xx_it.c` | 删除 RX 回调中的 `HAL_CAN_AddTxMessage` 回环发送，只保留 `osMessageQueuePut` 入队 |
| `Core/Src/stm32f1xx_it.c` | 新增 `HAL_CAN_ErrorCallback`，打印具体 CAN 错误类型（ACK/Bus-Off/Passive/...） |
| `Core/Src/stm32f1xx_it.c` | 添加 `#include <stdio.h>` |
| `App/tasks/arm_state_task.c` | `HAL_CAN_AddTxMessage` 添加返回值 `HAL_OK` 检查 |

### 另：CAN RX 队列长度调整

队列长度从 72 改到 16 后不再触发过载 — 旁证了 RX 流量不大，不需要大队列。

### 效果
`0x330` 状态报文正常发出，数据正确（夹爪脉宽 3000、J0 转速 0）。

## 2026-07-13 — CAN 硬件滤波 + PWM 打印 + 舵机安全启动 + 机械补偿架构

### 1. CAN 硬件滤波
**现象**：CAN 入口全通（mask=0），所有总线帧都进中断，无关流量干扰处理。
**修改**：`Core/Src/can.c` — 替换为 3 bank mask mode 滤波器。
| Bank | 模式 | 接受的 ID |
|:----:|:----:|:----------|
| 0 | mask (0x7FE) | 0x130 + 0x131 |
| 1 | mask (0x7FF) | 0x230 |
| 2 | mask (0x7FF) | 0x430 |

### 2. 串口输出 PWM CCR
**现象**：调试时看不到实际 PWM 输出值，无法判断舵机是否收到信号。
**修改**：`App/tasks/servo_task.c` — R2 printf 增加 `CH1/CH2/CH3` 实时 CCR 值。
```
J1= +954° J2=-1678° J3(G)=3000 | PWM: CH1=3000 CH2=3000 CH3=3000
```

### 3. Servo_Ta 栈溢出修复
**现象**：烧录后运行几秒死机。
**根因**：PRINTF 格式串变长，Servo_Ta 栈 128 words(512B) 不够用，溢出踩内存。
**修改**：`Core/Src/freertos.c` — `Servo_TaBuffer[128]` → `[256]`（翻倍到 1024B）。

### 4. 上电舵机无输出，首次激活才启动
**现象**：上电舵机自动回中/张开，可能损坏机械结构。
**根因**：`Servo_Init` 启动全部 PWM 通道，CH3/CH4 初值 1000（夹爪全开），上电即动。
**修改**：
| 文件 | 修改 |
|------|------|
| `App/drivers/servo.c` | `Servo_Init` 不再启动任何 PWM 通道；新增 `Servo_StartAll()` 供首次激活调用 |
| `App/drivers/servo.h` | 新增 `Servo_StartAll()` 声明 |
| `App/tasks/servo_task.c` | R1/R2 循环内加入 `static uint8_t activated` 标志，首次 `g_servo_active=1` 时启动 PWM + 设 current=target（R2） |
| `App/config/app_arm_cfg_r2.h` | 新增 `J1_ANGLE_OFFSET` / `J2_ANGLE_OFFSET` / `GRIPPER_PULSE_OFFSET` 宏 |
| `App/config/app_globals.h` | `ArmState_t` 新增 `j1_offset` / `j2_offset` / `gripper_offset` 字段 |

**效果**：
- 上电后全部通道静默，舵机软（无 PWM）
- `cansend can0 430#04` 解锁后首次激活，J1/J2 直接从目标角度开始
- CH3/CH4 初值改为 **3000（中位）**，激活后不会突跳

|------|------|
| `doc/测试指南.md` | 新增 R2 完整指令表 + 串口格式 + 常见问题排查 + 激活流程 |

\n## 2026-07-15 — 首次运动速度不受控修复 + 0x131 废弃 + 文档同步

### 现象
1. 上电后设置速度，第一个运动（回中）仍然以默认 180°/s 速度走
2. 0x131(ARM_VEL) 速度设置不生效
3. 锁定后发 0x130 可绕过

### 根因
1. 首次激活 `j1_current = j1_target` 跳过插值，舵机全速冲到位
2. can_rx_task.c 无 0x131 handler
3. 锁定用 `g_servo_active=0`，但 0x130 handler 无条件设 `g_servo_active=1`
4. `430#01` 回中不触发激活，设置的目标被后续 0x130 覆盖

### 修改

| 文件 | 修改 |
|------|------|
| `App/tasks/servo_task.c` | 首次激活改从 MT6701 读真实角度开始插值，不再 `current=target` 跳过 |
| `App/tasks/can_rx_task.c` | 分离 `g_system_locked` 和 `g_servo_active`；`430#01` 触发首次激活 |
| `App/tasks/can_rx_task.c` | 移除 0x131(ARM_VEL) handler，速度统一走 0x430#02 |
| `App/tasks/arm_state_task.c` | 0x330 flags 新增 bit2=系统锁定 |
| `App/config/app_globals.h` | 新增 `g_system_locked` 声明 |
| `Core/Src/freertos.c` | 定义 `g_system_locked` 变量 |
| `doc/测试指南.md` | 0x131→0x430#02 速度；关节命名修正(J0=基座,J1=大臂,J2=小臂,J3=夹爪)；中位值 3000→3200 同步 |
| `doc/留档.md` | 更新为最新状态 |

### 效果
- 先设速度再回中，第一个动作就按设定速度走
- `430#03` 锁定后 0x130 命令不会绕过
- 速度设置统一走 `430#02`，0x131 废弃

## 2026-07-14 — 锁定与速度设置 Bug 修复

### 现象
1. `430#03` 锁定后，下一个 `130#` 关节命令又让舵机动了（锁被绕过）
2. `131#` 速度设置命令完全不生效

### 根因
1. 锁定用了 `g_servo_active=0`，但每个 0x130 handler 都无条件 `g_servo_active=1`，锁被覆盖
2. can_rx_task.c 没有 0x131(ARM_VEL) 的 handler，走 catch-all

### 修改

| 文件 | 修改 |
|------|------|
| `App/config/app_globals.h` | 新增 `g_system_locked` 外部声明 |
| `Core/Src/freertos.c` | 定义 `g_system_locked` 变量 |
| `App/tasks/can_rx_task.c` | 三个 0x130 分支 `g_servo_active=1` 改为 `if (!g_servo_active) g_servo_active=1` |
| `App/tasks/can_rx_task.c` | 锁定/解锁改用 `g_system_locked` |
| `App/tasks/can_rx_task.c` | 新增 0x131(ARM_VEL) handler |
| `App/tasks/servo_task.c` | 输出条件改为 `g_servo_active && !g_system_locked` |
| `App/tasks/arm_state_task.c` | flags 新增 bit2=系统锁定 |

### 效果
- `430#03` 锁定后，发任何 0x130 指令都不会让舵机动
- `430#04` 解锁后恢复
- `131#01 00 B8 0B` 可以正常设 J1 速度
- 0x330 状态帧 bit2 显示锁定状态

| 文件 | 修改 |
|------|------|

| `App/tasks/can_rx_task.c` | R2 增量新增 `case 3` gripper 支持 |

| `App/tasks/servo_task.c` | R2 初始化 `gripper_target=3000` 防抱死 |
| `App/config/app_arm_cfg_r2.h` | 修正 `GRIPPER_PULSE_OPEN=5000`(全开), `CLOSE=3000`(安全底线) |

### 效果
- J1/J2 命令不会被软件忽略，超出 `J1_ANGLE_MIN/MAX` 自动钳位
- J3 解锁后到 3000 中位，不再抱死
- 多关节 J3 正确映射百分比到 CCR
- R2 增量 J3 可用

### 实测标定
```
J3: 5000=全开, 4000=半开, 3000=中位近夹, 2950=闭合, 2940=完全闭合, 2930=夹紧
```
