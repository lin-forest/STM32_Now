# 编码器配置说明

## 1. 实测标定数据

| 测量组 | 初始计数 | 转一圈后计数 | 差量 (ticks/rev) |
|--------|----------|-------------|-----------------|
| 第1组  | 46694    | 48472       | 1778            |
| 第2组  | 48869    | 50664       | 1795            |

---

## 2. 硬件参数

| 参数         | 值                          |
|--------------|-----------------------------|
| 电机减速比   | 1:34                        |
| 编码器类型   | 霍尔编码器，13 PPR（机械线数）|
| MCU          | STM32F103C8T6               |
| 编码器定时器 | TIM2（电机1）、TIM3（电机2）|
| 编码器模式   | Encoder Mode TI1 and TI2（4倍频）|
| 计数范围     | 0 ~ 65535（16位）           |
| PWM 定时器   | TIM1                        |

---

## 3. 分辨率推导

```
每圈 ticks = 机械线数 × 4倍频 × 减速比
           = 13 × 4 × 34
           = 1768 ticks/rev（输出轴）
```

**与实测对比：**

| 组别 | 实测 | 理论 | 误差   |
|------|------|------|--------|
| 第1组 | 1778 | 1768 | +0.57% |
| 第2组 | 1795 | 1768 | +1.53% |

误差 < 2%，属正常机械公差，结论：**编码器配置正确**。

---

## 4. TIM1 PWM 定时器配置

```
PSC = 72 - 1  →  计数时钟 = 72MHz / 72 = 1 MHz
ARR = 1000 - 1 = 999
PWM 频率 = 1MHz / 1000 = 1 kHz
```

对应 `app_config.h`：`PWM_MAX = 999`，与 ARR 完全一致 ✅

---

## 5. SPEED_TICKS_MAX 推算

控制周期 = 10ms，输出轴实际转速范围 200 ~ 300 RPM。

```
SPEED_TICKS = (RPM / 60) × 1768 × 0.01
```

| 输出轴转速  | 每控制周期 ticks |
|-------------|-----------------|
| 200 RPM     | ≈ 59            |
| 250 RPM     | ≈ 74            |
| 300 RPM     | ≈ 88            |
| **305 RPM** | **≈ 90（取值）**|

**结论：** `SPEED_TICKS_MAX = 90`，覆盖 300 RPM 上限并留有少量裕量 ✅

---

## 6. 配置核查结论汇总

| 配置项                          | 状态 | 说明                              |
|---------------------------------|------|-----------------------------------|
| TIM2/TIM3 编码器模式（0~65535）  | ✅   | 与硬件参数一致                    |
| TIM1 PWM_MAX = 999              | ✅   | 与 ARR = 1000-1 匹配              |
| 编码器分辨率 1768 ticks/rev      | ✅   | 实测误差 < 2%                     |
| MOTOR1_PID_TS = 0.01f（10ms）   | ✅   | 需确认中断计数满 10 次再调用 PID  |
| SPEED_TICKS_MAX = 90            | ✅   | 对应输出轴 ≈ 305 RPM（300 RPM 裕量）|
