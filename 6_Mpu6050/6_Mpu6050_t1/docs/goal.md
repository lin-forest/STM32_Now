## ❗1. 坐标系对齐（你当前系统必须做）

MPU6050 vs AK09911：

👉 很可能轴不一致

例如：

```text
MPU: X forward, Y left
AK:  X right,   Y forward
```

---

### ✅ 你必须做：

```c
// 举例（具体要测）
mag_x = raw_my;
mag_y = -raw_mx;
mag_z = raw_mz;
```

---

## ❗2. 磁校准（必须）

否则：

> ❌ yaw会乱跳 + 偏移

---

### 最低要求（你现在必须做）：

```c
mag_x -= offset_x;
mag_y -= offset_y;
mag_z -= offset_z;
```

---

### 推荐（下一阶段）：

* 椭球拟合（Python）
* 自动标定

---

## ❗3. 单位统一

Mahony要求：

```text
acc → 单位向量
mag → 单位向量
```

👉 所以：

```c
normalize(acc);
normalize(mag);
```
