## 二、硬件接线

### MPU6050 模块（I2C1）

| 模块引脚 | 接到 |
|---------|------|
| VCC | 3.3V |
| GND | GND |
| SCL | PB6 (I2C1_SCL) |
| SDA | PB7 (I2C1_SDA) |
| XDA / XCL | 悬空（不使用 MPU 的 Aux I2C） |
| AD0 | GND（I2C 地址 = 0x68） |
| INT | 悬空（使用轮询模式） |

### AK09911 模块（I2C1，与 MPU6050 共用总线）

| 模块引脚 | 接到 | 说明 |
|---------|------|------|
| VCC | 3.3V | |
| GND | GND | |
| SCL | PB6 (I2C1_SCL) | 与 MPU6050 共用 |
| SDA | PB7 (I2C1_SDA) | 与 MPU6050 共用 |
| CAD | **GND** | I2C 地址 = 0x0C，必须接，不能悬空 |
| RST | **3.3V** | 复位引脚，必须拉高，否则芯片持续复位无法响应 |
| TST | **GND** | 测试模式引脚，必须拉低 |

> ⚠️ **关键踩坑**：
> - `CAD` 悬空 → 地址不确定，I2C 无响应
> - `RST` 悬空 → 模块板下拉电阻将其拉低 → 芯片持续复位 → I2C 完全无响应
> - `TST` 悬空 → 可能进入测试模式，行为异常

## 八、待完成：硬铁校准

Yaw 长期稳定依赖硬铁校准，当前 offset 均为 0。

### 操作步骤

1. 将 IMU **水平放置**，保持平稳，绕 Z 轴缓慢旋转 **360°**
2. 串口记录全程 `mx`、`my`、`mz` 数据
3. 计算偏置：
   ```
   offset_x = (max_mx + min_mx) / 2
   offset_y = (max_my + min_my) / 2
   offset_z = (max_mz + min_mz) / 2
   ```
4. 填入 `imu_process.c` 中的硬铁补偿处
5. 验证：Python 画 `mx vs my` 散点图，圆形表示校准成功

### 验证指标

| 指标 | 未校准 | 校准后 |
|------|--------|--------|
| mx vs my 散点图 | 偏心椭圆 | 以原点为圆心的圆 |
| 静置 Yaw 稳定性 | 缓慢漂移 | 长期不动 |
| 绕Z旋转 Yaw 变化 | 非线性 | 平滑线性 |
