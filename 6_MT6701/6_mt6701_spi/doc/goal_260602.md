# 一、接线

你这个模块：

```text
VCC
GND
NCS/Z
SCLK/B
MISO/A
NC
```

SSI模式接法：

| MT6701 | STM32 |
| ------ | ----- |
| VCC    | 3.3V  |
| GND    | GND   |
| NCS/Z  | PA4   |
| SCLK/B | PA5   |
| MISO/A | PA6   |

即：

```text
SPI1

PA4  -> CS
PA5  -> SCK
PA6  <- MISO
```

不需要：

```text
MOSI
```

# 五、读取函数

建立：

```c
uint16_t MT6701_ReadRaw(void)
```

代码：

```c
uint16_t MT6701_ReadRaw(void)
{
    uint8_t rx[2];

    MT6701_CS_LOW();

    HAL_SPI_Receive(
        &hspi1,
        rx,
        2,
        100
    );

    MT6701_CS_HIGH();

    uint16_t data;

    data =
        ((uint16_t)rx[0] << 8)
        | rx[1];

    data >>= 2;

    return data & 0x3FFF;
}
```

这里：

```text
14bit角度
```

位于：

```text
15~2
```

所以：

```c
>>2
```

# 六、角度转换

```c
float MT6701_GetAngle(void)
{
    uint16_t raw;

    raw = MT6701_ReadRaw();

    return
        raw
        *
        360.0f
        /
        16384.0f;
}
```

# 下一阶段

当这个跑通以后：

不要立刻DMA。

下一步应该做：

```text
读取原始角度
    ↓
角度展开
    ↓
跨0点处理
    ↓
多圈角度
```

例如：

```text
359°
→
0°
```

不能认为：

```text
-359°
```

而是：

```text
+1°
```

这是舵轮控制真正需要的部分。
